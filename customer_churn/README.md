# Customer Churn

## Project Overview

Predict whether a bank customer is likely to leave based on demographics, product usage, and account behavior.

## Workflow

Raw data -> preprocessing -> feature engineering -> model comparison -> evaluation -> saved model -> Streamlit app.

## Project Architecture

```text
data/raw/        Original dataset
notebooks/       Original exploratory notebook
src/             Modular training, prediction, evaluation, and utilities
models/          Saved model artifacts
outputs/         Reports, charts, predictions, and metrics generated by training
app/             Streamlit interface
docs/            Business, architecture, data, model, deployment, and user docs
```

## Installation

From the repository root:

```bash
pip install -r requirements.txt
```

## Usage

```bash
cd customer_churn
python src/train.py
streamlit run app/streamlit_app.py
```

## Results

Training saves `outputs/model_leaderboard.csv`, `outputs/classification_report.csv`, and `outputs/confusion_matrix.png`.
